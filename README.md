## 📌 Featured Projects

**[movie-recommender-system](https://github.com/ZimalYousuf3/movie-recommender-system)**
A hybrid movie recommender system built on the MovieLens dataset, combining content based filtering (genre similarity) and collaborative filtering (user rating patterns) into a single blended recommendation engine.

**[sms-spam-detection-nlp](https://github.com/ZimalYousuf3/sms-spam-detection-nlp)**
An NLP based spam detection project using NLTK for text cleaning, TF-IDF for vectorization, and comparing Naive Bayes vs Logistic Regression on the real world SMS Spam Collection dataset.

**[Mall-Customer-Segmentation](https://github.com/ZimalYousuf3/Mall-Customer-Segmentation)**
Customer segmentation using K-Means clustering on the Mall Customer dataset, grouping customers by income and spending behavior into clear, human readable personas.

**[House-Price-India-Prediction](https://github.com/ZimalYousuf3/House-Price-India-Prediction)**
Regression project predicting Indian house prices using Linear Regression and Random Forest, with full EDA and feature importance analysis.

**[ML-Fundamentals-Practice](https://github.com/ZimalYousuf3/ML-Fundamentals-Practice)**
Ongoing practice repository covering EDA, preprocessing, and supervised/unsupervised learning across multiple real world datasets.

**[sentiment-analyzer](https://github.com/ZimalYousuf3/sentiment-analyzer)**
AI-powered sentiment analyzer using Hugging Face Transformers, classifying customer reviews with a summary report.

**[huggingface-nlp-basics](https://github.com/ZimalYousuf3/huggingface-nlp-basics)**
Beginner-friendly practice with Hugging Face Transformers and Inference API for text generation and sentiment analysis.
